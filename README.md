# 💰 Shared Wallet

**Collaboration for Shared Finances!**

Shared Wallet is a collaborative financial planning app that helps groups organize, track, and manage shared expenses. Users can create shared wallets, invite members, set budgets, track and split expenses, store receipts, and monitor spending—all in one centralized workspace.

Built with **React Native, Expo, and TypeScript**, Shared Wallet is currently in development as an MVP.
